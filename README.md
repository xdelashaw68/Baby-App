# Baby-App

JeanLuc's Light Show: slow, bold, high-contrast animations for a young baby, made to run full screen on an iPad.

- Nine scenes (aurora ribbons, bullseye, shapes, faces, waves, pinwheel, lava, tracker ball, camera mirror)
- Touch blooms, music that the visuals dance to, and optional voice/movement responses
- Hold the corner button to open the controls

Live at **https://xdelashaw68.github.io/Baby-App/** once GitHub Pages is turned on (Settings › Pages › Deploy from a branch › `main` / root).

Everything runs in the browser. Camera and microphone are only used when turned on, and nothing leaves the device.
